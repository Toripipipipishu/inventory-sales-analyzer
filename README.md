# Inventory Sales Analyzer

小売店舗向けの在庫・販売分析／発注支援ツールです。

## 概要

POSや販売履歴、在庫データをもとに、
商品ごとの販売速度・在庫回転・売上傾向などを分析し、
仕入れや発注判断を支援することを目的としています。

実際の店舗運営・在庫管理・仕入れ経験をもとに、
単純な集計ではなく「次に何を仕入れるべきか」が
判断しやすい仕組みを目指しています。

## 主な機能（予定）

- CSVデータの読み込み
- 商品別売上分析
- 販売速度の算出
- 在庫回転の分析
- 滞留在庫の抽出
- 発注候補商品の抽出
- ABC分析
- 分析結果の可視化

## 開発方針

生成AIを開発支援に活用しながら、

課題整理 → 要件定義 → 仕様設計 → 実装 → テスト → 改善

の流れで開発しています。

## 想定用途

- 小売店舗の在庫管理
- 発注支援
- 売上分析
- 不動在庫の抽出
- 店舗業務の効率化
